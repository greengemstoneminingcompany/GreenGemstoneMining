# Source-backed website additions

The research feature adds eight project dossiers; three identified 2022 XRF sample records; buyer specifications for mica, copper, lead and tantalum/niobium interests; dated community, excavation and operating history; a development-review guide; and optional structured enquiry context. Original English source summaries are labelled as such alongside localized controls in the four site languages.

The existing map gains 208 individually indexed field observations, host-rock and project filters, clustering, zoom and row-level details. Historical routes are loaded only when the field layer is opened. The 42 unconverted follow-up/grid records remain a review table, not fabricated licence boundaries. No laboratory sample is assigned to an unproven field location.

Stable S-prefixed evidence IDs in the source-reference disclosures correspond to the owner's downloadable evidence register. That private register names the original documents, their current local paths, original pages/paragraphs/worksheet rows and website code lines. Public code contains edited summaries and survey values, not original contracts, personal records or credentials.

Photos and videos remain under owner control through ImageKit. No media was uploaded or replaced by this change, and existing ImageKit folders remain unchanged. Private financial records, draft partner terms and uncertain technical claims were not published as current facts. Existing owner/evidence features are preserved; external monitoring drafts were not activated.
